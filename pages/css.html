Guia de CSS

O que é CSS?

CSS é a linguagem usada para estilizar páginas web.

Formas de uso

  • Inline
  • Interno
  • Externo
/* Externo */
style.css

/* Interno */
<style> p { color: red; } </style>

/* Inline */
<p style="color:red">Texto</p>

Seletores

  • Elemento (p)
  • Classe (.minha-classe)
  • ID (#meu-id)

Cores

  • hex (#fff)
  • rgb()
  • rgba()

  • border
