Guia de JavaScript

O que é JavaScript?

JavaScript é uma linguagem de programação usada para criar interatividade em páginas web, como animações, formulários dinâmicos e sistemas completos.

Como usar JavaScript

  • Inline
  • Interno
  • Externo
/* Externo */
script.js

/* Interno */
<script>
  console.log("Olá mundo");
</script>

/* Inline */
<button onclick="alert('Olá')">Clique</button>
