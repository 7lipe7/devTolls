Guia de HTML

O que é HTML?

Linguagem de marcação usada para estruturar páginas web.

Estrutura básica

<!DOCTYPE html>
<html>
  <head>
    <title>Título</title>
  </head>
  <body>
    Conteúdo
  </body>
</html>

Principais Tags

  • <h1> até <h6>
  • <p>
  • <a>
  • <img>

Listas

  • <ul>
  • <ol>
  • <li>

Formulários

  • <form>
  • <input>
  • <button>

Dicas

  • Feche todas as tags
  • Use identação
  • Use HTML semântico

HTML Semântico

  • <header>
  • <main>
  • <section>
  • <article>
  • <footer>

Ajuda na organização e SEO do site.

Links

  • <a href="url">
  • target="_blank"

Usado para navegação entre páginas.

Botões em HTML

  • <button>
  • type="button"
  • type="submit"
  • type="reset"

Usado para executar ações na página.

<button>Clique aqui</button>

<button type="submit">Enviar</button>

<button type="reset">Limpar</button>

Imagens

  • <img src="" alt="">

O atributo alt melhora acessibilidade.

Tabelas

  • <table>
  • <tr>
  • <td>
  • <th>

Usado para dados organizados em linhas e colunas.

  • <input type="text">

  • <textarea>
  • <select>

Atributos HTML

  • id
  • class

Multimídia

  • <audio>
  • <video>

Permite adicionar áudio e vídeo no site.

Comentários

<!-- Isso é um comentário -->

Não aparece na página final.

Entidades HTML

  • &lt; = <
  • &gt; = >
  • &amp; = &

Boas práticas

  • Use tags semânticas
  • Indentação correta
  • Evite excesso de <div>
  • Use nomes de classes organizados

Links em HTML

  • <a href="">
  • target="_blank"
  • mailto:
  • tel:

Usado para navegar entre páginas ou sites.

<a href="https://google.com">Google</a>

Validação de Formulários

  • required
  • min
  • max
  • maxlength
  • pattern
<input type="text" required>
<input type="number" min="1" max="10">
<input type="text" maxlength="20">

Meta Tags (SEO)
