devTools

Um site para tirar suas dúvidas sobre desenvolvimento web

HTML

A linguagem para construir páginas da web

Exemplo de HTML:

<!DOCTYPE html>
<html>
<body>

<h1>Título</h1>
<p>Parágrafo</p>

</body>
</html>

CSS

A linguagem para estilizar páginas web

Exemplo de CSS:

body {
  background-color: lightblue;
}

h1 {
  color: white;
}

JavaScript

A linguagem para programar páginas web

Exemplo de JavaScript:

function minhaFuncao() {
  document.body.style.background = "red";
}
